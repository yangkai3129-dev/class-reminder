# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-10-08
**Phases:** 1-3
**Total Plans:** 6

## Overview

给教培机构全职同事用的本地小工具：为每个学生/班级建一份自定义文案的上课提醒模板，每天只需确认或微调「上课时间」「教室号」「老师姓名」三个空，点确认即把完整文案复制到剪贴板，同事手动粘贴进企业微信客户群。形态是「排课脚本式」本地程序——Python 3 标准库 + 本地 HTTP 服务 + 浏览器界面 + JSON 文件存储，零第三方依赖、无签名、无到期。

## Phases

### Phase 1: 数据底座 — 档案与教室管理

**Goal**: 同事能用本地程序建/改/删学生档案，并维护分「班课教室」「VIP教室」两类的教室号名单
**Depends on**: Nothing (first phase)
**Requirements**: PROF-01, PROF-02, PROF-03, ROOM-01
**Plans**: 2 plans

Plans:

- [x] 01-01: Walking Skeleton + 档案 CRUD（建/改/删档案，含 `{时间}`/`{教室号}`/`{老师}` 占位符模板）
- [x] 01-02: 教室名单 CRUD（班课教室/VIP教室 两类增/删/改）

**Success Criteria:**

1. 同事启动本地程序后能在浏览器打开界面，界面遵守 Apple 设计规范
2. 同事能创建新学生/班级档案，输入含 `{时间}`、`{教室号}`、`{老师}` 三个占位符的自定义模板
3. 同事能编辑已有档案的模板文字、删除已有档案
4. 同事能维护教室号名单，按「班课教室」「VIP教室」两类增/删/改
5. 档案与教室数据持久化到本地 JSON 文件，重启程序后仍在

### Phase 2: 每日填写

**Goal**: 同事打开学生档案即可确认或微调时间、教室、老师三个字段
**Depends on**: Phase 1
**Requirements**: FILL-01, FILL-02, FILL-03, FILL-04, ROOM-02
**Plans**: 2 plans

Plans:

- [x] 02-01: 数据闭环（后端 last_* 持久化 + 填写视图 + 预填 + 确认存值，直接输入形态）
- [x] 02-02: 点选/滚轮形态（时间双滚轮 + 教室分组点选 + 全局开关切换）

**Success Criteria:**

1. 打开某学生时，时间、教室号、老师已预填该学生上一次的值
2. 同事用苹果式「开始时间 + 结束时间」滚轮选择上课时间
3. 同事能从教室名单点选教室号（「班课教室」「VIP教室」分组显示）
4. 同事能手打老师姓名
5. 同事能通过全局开关在「点选/滚轮」与「直接输入」间切换（作用于时间、教室，老师始终手打）

### Phase 3: 生成与复制

**Goal**: 同事一键核对完整渲染文案并复制进剪贴板
**Depends on**: Phase 2
**Requirements**: COPY-01, COPY-02, COPY-03
**Plans**: 2 plans

Plans:

- [x] 03-01: 核对弹窗与只读渲染（确认 → 弹窗 → 修改/确认复制，含 D-04/D-05 + writeText 主路径复制）
- [x] 03-02: 三级复制降级链（execCommand 降级 + D-03 手动兜底 + 状态复位）

**Success Criteria:**

1. 点「确认」后弹出核对弹窗，显示完整渲染文案（占位符已替换为当前值）
2. 核对弹窗提供「修改」（返回编辑）与「确认复制」（复制到剪贴板）两个选项
3. 确认复制后完整文案进入系统剪贴板，可直接粘贴进企业微信客户群

## Milestone Summary

**Decimal Phases:**

- *(none)*

**Key Decisions:**

- 形态 = Python 脚本 + 本地网页，而非苹果原生 app（用户要求「不是苹果 app、无使用期限」）
- 时间字段 = 「起-止」两段，苹果事件式双滚轮（真实文案 9:00-10:30 总是两段）
- 教室号 = 固定名单点选，分「班课教室」「VIP教室」两类
- 新增 `{老师}` 占位符，手打、无名单
- 全局「点选/滚轮 ⇄ 直接输入」切换（作用于时间、教室，老师始终手打）
- 时间/教室/老师默认带出上一次的值（课表大多不变，加快每日流程）
- 服务器只 bind 127.0.0.1（零依赖、无鉴权单用户本地工具，本机回环即安全边界）
- 教室分类内部值存 `class`/`vip`（不存中文），中文文案仅前端映射
- 新增 `--no-browser` 启动参数（供自动化验证/CI 抑制浏览器弹窗）
- 复制用三级降级链 writeText → execCommand → 手动 ⌘C 全选（Safari/Chrome 受限场景永不卡死）
- 核对弹窗只读渲染走 textContent（用户自输入数据进 DOM 的唯一入口，防 XSS）

**Issues Resolved:**

- 预填值经「确认存值」后未回写内存 profile，导致滚轮打开时不滚到已存时间（WR-02）→ 修复：镜像保存的 fill 值进内存 profile
- 滚轮在视图尚未渲染时定位失败 → 修复：先显示填写视图再渲染滚轮
