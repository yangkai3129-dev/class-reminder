# Requirements Archive: v1.0

**Archived:** 2026-10-08
**Core Value:** 把「每天给每个学生编一条明日上课提醒」从「手敲文案」降到「确认默认值 + 一键复制」

## v1 Requirement Outcomes

All 12 v1 requirements shipped and **validated** (human UAT + verification on every phase).

### 档案管理 (PROF)

- [x] **PROF-01**: 同事能为新学生/班级创建档案，档案含一段自定义模板（固定文字 + `{时间}`、`{教室号}`、`{老师}` 三个占位符）— **Validated** (Phase 1)
- [x] **PROF-02**: 同事能编辑已有档案的模板文字 — **Validated** (Phase 1)
- [x] **PROF-03**: 同事能删除已有档案 — **Validated** (Phase 1)

### 教室名单 (ROOM)

- [x] **ROOM-01**: 同事能维护固定教室号名单，教室分「班课教室」「VIP教室」两类（添加/编辑/删除）— **Validated** (Phase 1)
- [x] **ROOM-02**: 同事能从教室名单点选教室号（两类分组显示），无需手输 — **Validated** (Phase 2)

### 每日填写 (FILL)

- [x] **FILL-01**: 同事打开某学生时，`{时间}`、`{教室号}`、`{老师}` 已预填该学生上一次的值 — **Validated** (Phase 2)
- [x] **FILL-02**: 同事能用苹果式「开始时间 + 结束时间」滚轮选择上课时间 — **Validated** (Phase 2)
- [x] **FILL-03**: 同事能手打老师姓名 — **Validated** (Phase 2)
- [x] **FILL-04**: 同事能通过全局开关在「点选/滚轮」与「直接输入」之间切换，作用于时间、教室两字段（老师始终手打）— **Validated** (Phase 2)

### 生成与复制 (COPY)

- [x] **COPY-01**: 同事点「确认」后弹出核对弹窗，显示完整渲染文案 — **Validated** (Phase 3)
- [x] **COPY-02**: 核对弹窗提供「修改」（返回编辑）与「确认复制」（复制到剪贴板）两个选项 — **Validated** (Phase 3)
- [x] **COPY-03**: 确认复制后完整文案进入系统剪贴板，可直接粘贴进企业微信客户群 — **Validated** (Phase 3)
