**dist/启动.command（Mac，LF 行尾，需 chmod +x）：**
```bash
#!/bin/bash
cd "$(dirname "$0")"
if ! command -v python3 >/dev/null 2>&1; then
  echo "未找到 python3。Mac 请先安装 Python 3：https://www.python.org/downloads/"
  read -r -p "按回车键退出..."
  exit 1
fi
python3 class_reminder.py
```

**dist/启动.bat（Windows，CRLF 行尾）：**
```bat
@echo off
cd /d "%~dp0"
python class_reminder.py 2>nul
if not errorlevel 1 goto done
py -3 class_reminder.py 2>nul
if not errorlevel 1 goto done
echo 未找到 Python 3。请到 https://www.python.org/downloads/ 安装，
echo 并在安装时勾选 "Add Python to PATH"。
:done
pause
```

# 上课提醒 · 使用说明

给教培机构同事用的本地小工具：为每个学生/班级建一份自定义文案的上课提醒模板，每天只需确认「上课时间」「教室号」「老师姓名」三个空，点确认即把完整文案复制到剪贴板，手动粘贴进企业微信客户群。

## 需要什么

- **Python 3**（只依赖标准库，不需要装任何第三方包）
  - Mac：通常自带（终端运行 `python3 --version` 可查）
  - Windows：到 https://www.python.org/downloads/ 安装，安装时务必勾选 **Add Python to PATH**

## 怎么启动

- **Mac**：双击 `启动.command`（若提示无权限，先打开终端运行一次 `chmod +x 启动.command`）
- **Windows**：双击 `启动.bat`
- 或任意终端进入本文件夹后运行：`python3 class_reminder.py`（Windows 为 `python class_reminder.py`）

启动后浏览器会自动打开 http://127.0.0.1:8000 。关掉浏览器、在终端按 Ctrl+C 或直接关窗口即停止。

## 数据存在哪

所有数据都存在本文件夹的 `data.json` 里（自动创建、自动保存）。把**整个文件夹**复制给下一位同事，数据就一起带过去了。

## 出厂自带内容

`data.json` 已预置教室名单：

- 班课教室：2801、2802、2804–2818、2821–2824
- VIP 教室：V01–V40

学生档案为空，第一次使用点「新建档案」即可。

## 常见问题

- **换电脑 / 给同事**：把整个文件夹（含 `class_reminder.py`、`static/`、`data.json`、启动器）复制过去即可。
- **想彻底重置**：删除 `data.json`，下次启动会生成一份空档案 + 空教室名单（注意：这样会丢掉自带教室名单，需手动重新添加）。
- **端口被占用**：在终端运行 `python3 class_reminder.py --port 8080` 换端口。

## 安全说明

程序只监听本机 127.0.0.1，不上传、不联网、不碰微信 API；发送靠手动粘贴。
