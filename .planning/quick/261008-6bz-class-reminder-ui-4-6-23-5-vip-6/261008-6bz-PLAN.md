# 261008-6bz class-reminder UI 改版

用户 6 条 UI 需求（已逐条确认口径）：

1. 侧栏固定不随滚动，右侧内容区滚动
2. 档案双视图：列表 ↔ 卡片（圆角卡片、随宽换行、只显示名字、按拼音首字母排、点卡进填写、编辑在卡右端、悬停右上角 × 删除）
3. 档案右上角搜索框：实时筛选 + 回车也生效，按姓名包含
4. 时间 4 滚轮：开始/结束各拆「小时+分钟」，小时 6–23，分钟 0/5/…/55
5. 填写页教室号「班课/VIP」切换，一次只显示一类
6. 教室管理：网格一排 6 个，数字自然序排，管理态 × 删除（带确认）

统一决定：
- 删除确认统一「否(左·白) / 是(右·蓝)」，替换现有「取消/删除(红)」
- 英文名按拉丁首字母排（排在拼音前，不额外做拼音表混排）
- 教室网格正常态点 tile 打开编辑（保留改房间号能力），管理态点 tile 无操作

涉及文件：static/style.css、static/index.html、static/app.js（源码，不动 class_reminder.py）

## Tasks

1. **布局与教室**：侧栏固定 + 教室网格 + 管理态删除 + 确认弹窗改否/是
2. **档案双视图 + 搜索**：视图切换、卡片渲染、拼音排序、搜索框
3. **填写页**：时间 4 滚轮 + 教室班课/VIP 切换

每 task 一个原子提交。完成后 `node --check` 校验 JS + 只读冒烟。
