# 生成与复制 — 三级复制降级链（execCommand 降级 + D-03 手动兜底）

## Phase Goal (user story)

**As a** 教培机构同事，**I want to** 点「确认」后看到核对文案并一键复制，**so that** 每天少敲字、少错字。

> 本计划在 03-01 的「writeText 主路径」之上补齐第二级 `document.execCommand('copy')` 降级与第三级 D-03 手动 ⌘C 兜底，使「复制永不卡死」成为硬保证，并完善弹窗状态复位与选择正确性。

<objective>
把 03-01 的 `handleCopyConfirm` 从「writeText → 手动全选」两级升级为「writeText → execCommand('copy') → 手动全选」三级降级链。新增 `legacyCopy(text)`（隐藏 textarea offscreen + execCommand），在 writeText 失败后作为第二级；第三级维持 03-01 的 `selectRenderedText` + 「请按 ⌘C 手动复制」提示。同时修正手动全选的时机与选择保持（Pitfall 3），并确保每次打开弹窗状态复位。

Purpose: 交付 COPY-03 的完整可靠性——Safari/Chrome 下 writeText 失败时仍有 execCommand 可兜底，再失败落到手动 ⌘C，核心动作永不卡死。
Output: static/app.js 新增 legacyCopy 与三级链整合；弹窗状态复位与选择正确性修正。后端与 index.html/style.css 不变。
</objective>

    1. 新增 `legacyCopy(text)`（返回 boolean）：
       - 创建 `const ta = document.createElement("textarea");`，`ta.value = text;`，`ta.setAttribute("readonly", "");`；
       - 样式设为 offscreen：`ta.style.position = "fixed"; ta.style.left = "-9999px";`（**禁止** `display:none`，Pitfall 4）；
       - `document.body.appendChild(ta);` 后 `ta.select();` 再 `ta.setSelectionRange(0, ta.value.length);`；
       - `let ok = false;` 在 try 内 `ok = document.execCommand("copy", false, null);` catch 置 `ok = false`；finally 内 `document.body.removeChild(ta);` 移除节点；返回 ok。
    2. 整合进 handleCopyConfirm：在 03-01 的 writeText try/catch 之后、失败分支之前，插入 `if (!ok) ok = legacyCopy(renderedText);`，使链序变为 `writeText → legacyCopy → selectRenderedText + showCopyStatus("请按 ⌘C 手动复制", true)`。成功仍走 03-01 的 `showCopyStatus("已复制到剪贴板", false)` + copyDone=true + 按钮切「完成」。
    3. 不要改动 openCopyModal / closeCopyModal / finishCopyModal / handleCopyConfirmClick / renderCopyText 的既有行为。
  </action>
