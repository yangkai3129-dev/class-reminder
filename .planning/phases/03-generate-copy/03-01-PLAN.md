# 生成与复制 — 核对弹窗与只读渲染（确认 → 弹窗 → 修改 / 确认复制）

## Phase Goal (user story)

**As a** 教培机构同事，**I want to** 点「确认」后看到核对文案并一键复制，**so that** 每天少敲字、少错字。

> 本计划交付核对弹窗这一垂直切片：点「确认」→（校验+存值）→ 弹出核对弹窗显示完整渲染文案 → 「修改」回填写视图（值保留）/「确认复制」复制进剪贴板 → 「完成」回档案列表。复制先以主路径 `navigator.clipboard.writeText` 交付，二级 `document.execCommand('copy')` 降级链在 03-02 补齐（03-02 负责「永不卡死」的完整三级链）。

<objective>
把 Phase 2 的「确认 → 校验+存值 → 回列表」改为「确认 → 校验+存值 → 打开核对弹窗」。核对弹窗覆盖在填写视图之上（不改 activeView），只读渲染 profile.template 用当前 last_time/last_room/last_teacher 替换占位符后的完整文案；「修改」关弹窗回填写视图（值保留）、「确认复制」写进系统剪贴板并停留显示「已复制到剪贴板」、点「完成」回档案列表。同时补齐 D-04 点选模式的空教室校验缺口。

Purpose: 让同事第一次能在「确认」后**看见**完整渲染文案并可返回修改，再一键复制——覆盖 COPY-01 / COPY-02，并为 COPY-03 交付主路径。
