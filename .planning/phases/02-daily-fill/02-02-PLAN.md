# 每日填写 — 点选/滚轮形态 + 全局开关

## Phase Goal (user story)

**As a** 教培机构同事，**I want to** 打开学生档案即可确认或微调「上课时间」「教室号」「老师」三个字段，**so that** 每天不必手敲文案，只需确认默认值、一键保存。

> 本计划在 02-01 的数据闭环之上补齐「点选/滚轮」形态（时间双滚轮 + 教室分组点选）与全局「点选/滚轮 ⇄ 直接输入」开关，使两种输入形态可按全局偏好切换。
