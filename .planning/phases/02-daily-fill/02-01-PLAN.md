# 每日填写 — 数据闭环（直接输入形态）

## Phase Goal (user story)

**As a** 教培机构同事，**I want to** 打开学生档案即可确认或微调「上课时间」「教室号」「老师」三个字段，**so that** 每天不必手敲文案，只需确认默认值、一键保存。

> 本计划先交付「直接输入」形态的最小端到端闭环：打开 → 预填 → 修改 → 确认 → 存值 → 返回列表。点选/滚轮形态与全局开关在 02-02 计划补齐。

<objective>

Purpose: 让同事第一次能用本工具完成「打开→确认→存值」的每日填写流程（尚为直接输入形态）。
Output: class_reminder.py 新增 fill 持久化；static/ 新增填写视图 + 预填 + 确认存值逻辑。
