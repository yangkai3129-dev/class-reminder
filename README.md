# 上课提醒 class-reminder

给教培机构同事用的本地小工具：为每个学生建一份自定义文案的上课提醒模板，每天只需确认「上课时间」「教室号」「教师」三个空，点一下就把完整文案复制到剪贴板，粘贴进企业微信客户群即可。

> 把「每天给每个学生手敲一条提醒」降到「确认默认值 + 一键复制」。

## 功能

- **学生档案**：每个学生一份自定义模板，固定文案 + `{时间}` `{教室号}` `{教师}` 三个占位符
- **双视图**：列表 / 卡片切换，卡片按拼音首字母排序，右上角姓名搜索
- **每日填写**：三个空自动带出上一次的值，微调后一键复制
- **教室名单**：班课 / VIP 两类，网格管理
- **数据导出 / 导入**：一键备份、恢复、交接
- **零依赖**：Python 3 标准库 + 浏览器界面，无签名、无到期

## 下载与安装

1. 到本仓库右侧 **Releases** 页面，下载最新版的 `上课提醒.zip`。
2. 解压到任意文件夹。
3. 首次使用需要 Python 3：
   - **Mac**：双击 `启动.command`，按提示安装即可。
   - **Windows**：到 <https://www.python.org/downloads/> 装 Python，**务必勾选「Add python.exe to PATH」**。
4. 双击 `启动.command`（Mac）或 `启动.bat`（Windows），浏览器自动打开即可用。

## 更新（不丢数据）

1. 下载最新版 `上课提醒.zip`。
2. 解压，覆盖到原来的文件夹。
3. 你的所有数据都存在 `data.json` 里，**更新包里没有这个文件**，覆盖更新不会丢数据。

## 备份与交接

- 侧栏底部「导出数据」→ 下载一份备份 JSON；「导入数据」→ 选备份文件载入。
- 或直接复制文件夹里的 `data.json` 文件。

## 技术栈

Python 3 标准库 + 本地 HTTP 服务 + HTML/CSS/JS + JSON 文件存储，零第三方依赖。
